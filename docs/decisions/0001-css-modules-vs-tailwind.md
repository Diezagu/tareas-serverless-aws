
# 0001 - CSS Modules vs Tailwind 

- Estado: Aceptado
- Fecha: 2026-10-26

## Contexto
Se necesitaba una herraamienta para crear los estilos.

## Opciones consideradas
- CSS Modules (vanila CSS)
- TailwindCSS

## Decisión
Se decidio utilizar CSS modules ya que, a pesar de ser una herrmienta un poco mas compleja, se necesitaba
conocer ampliamente como funciona CSS desde cero, que es la finalidad de todo este curso.

## Consecuencias
La parte buena de esto, si estamos aprendiendo CSS, sin embargo, perdemos la rapidez y eficacioa de
utlizar un motor como Tailwind
